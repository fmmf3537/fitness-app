## 1. 现状诊断

对 8 个主要页面做了真机视口截图（430×930，证据见 `.diag/uix-screens/01~09`）。
应用功能完整、UIX-01 语义色约定执行到位，但从"能用"到"好看"还有明显差距：

| # | 问题 | 证据 | 影响 |
|---|------|------|------|
| P1 | **内外割裂** | 登录页是完整的品牌渐变 + Logo + 底部卡片设计（`01-login.png`）；进入应用后只剩灰底 + 黑字标题 | 第一屏承诺的品质感没有延续，像两个团队做的 |
| P2 | **零品牌色应用** | 全站只有 indigo-600 按钮一个品牌触点；页头、背景、图表全部中性灰 | 没有视觉记忆点，截图认不出是自己的 App |
| P3 | **卡片平淡无层级** | 唯一卡片规格 = 白底 + gray-200 1px 描边 + shadow-sm（`Card.jsx`） | 信息密度高的页面（日历、设置）一片"白纸"，视觉疲劳 |
| P4 | **数据无视觉表达** | 首页统计是裸数字 "3 / 4"；趋势页统计卡横向滚动且右缘被裁切（`03-trends.png` "最佳负重"被切断） | 关键指标不抢眼；裁切是实际布局 bug |
| P5 | **页头无层级** | 每个页面都是 "健身看板" 黑字 + 页面大标题，占两行行高 | 首屏有效信息被压缩 |
| P6 | **日历格无状态语言** | 训练日 = 一个小绿点，其余全白盒 | 训练记录是核心数据，却最不被强调 |
| P7 | **计划页单调** | 14 行 "日期 · 休息日" 完全同质，无视觉扫描锚点（`07-plans.png`） | 长列表无法快速定位 |
| P8 | **图表默认皮肤** | ECharts 默认轴线/图例样式，主色只有生硬的 indigo 平涂 | 数据页本应是最"酷"的页面 |

## 2. 设计方向（两案，任选其一）

### 方向 A · 暗夜能量（Dark）
- 深海军蓝底 + indigo→violet 霓虹渐变，玻璃拟态卡片，本周进度环形仪表
- 优点：极具运动 App 力量感，图表在深色下非常出彩
- 代价：全站主题翻转，ECharts/截图导入等 8 个页面全部需要深色适配，工作量最大

### 方向 B · 晨光轻量（Light，推荐）
- 保留浅色主题：渐变品牌页头（与登录页同款语言）+ 彩色图标统计卡 + 训练日紫色Tint日历格 + 下次训练横幅
- 优点：改动可控、与现有 UIX-01 语义色约定完全兼容、白天可读性最好；登录页→首页体验连续
- 代价：个性冲击力弱于方向 A

两案共同的设计令牌：
- 品牌渐变：`linear-gradient(150deg, #4f46e5, #7c3aed, #9333ea)`（仅页头/横幅/激活态，不大面积铺色）
- 圆角：卡片 20px、内嵌元素 12px、胶囊按钮 999px
- 阴影：三级（卡片 6% 透明度软阴影 / 悬浮 8% / 品牌横幅带 30% 紫色辉光）
- 数据表达：环形进度（周目标）、图标彩 chip（语义色 violet/blue/amber）、训练日单元格 Tint + 主项标签
- 日历：今日 = 2px 品牌描边；训练日 = 淡紫 Tint + 加粗 + 训练主项名

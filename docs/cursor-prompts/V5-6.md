### 1. `pages/CoachChatPage.jsx` 新建

默认导出 `CoachChatPage` 组件，整体结构（**借鉴 ReportChatSection 但做独立页**）：

```
[Header]  跟教练聊聊    [清空对话] 按钮（右侧，danger 色）
[历史区 threadRef]
  - 空态：居中提示 "跟教练说点什么吧——比如「我深蹲时膝盖疼，下周训练怎么调？」"
  - 加载中：骨架或 "加载中…"
  - 错误：红色 <p role="alert">{error}</p>
  - 消息列表：按 created_at 正序
    - user 右气泡：bg-indigo-600 text-white（与 ReportChatSection 对齐）
    - assistant 左气泡：bg-gray-100 + SimpleMarkdown
    - 每条可选显示小字：tokens / cost（如有）
[底部输入区]
  - 大 textarea（rows=3），回车发送，Shift+回车换行
  - 右侧 "发送" 按钮（sending 时禁用显示"发送中…"）
  - 失败重试：保留输入内容 + 同一 client_request_id 重发
```

#### 状态
```js
const [messages, setMessages] = useState([])
const [loaded, setLoaded] = useState(false)

```

#### 关键函数
- `load()` —— `api('/api/coach/chat')` 拉历史；404/401 → '未登录'，其他 → err.message
- `handleSend()` —— 校验非空 + 生成 client_request_id (`uuidv4()`)；发送 POST；拿到 user + assistant 后追加到 messages；清空 input；滚动到底部
- `handleRetry()` —— `failed` 非空时重发（同一 requestId）；成功后清空 failed
- `handleClear()` —— `window.confirm("确定清空所有对话？此操作不可恢复")`；DELETE 清空；setMessages([])
- 滚动到底部：useEffect 监听 messages 变化，scrollTo({top: scrollHeight})

#### 样式
- 整页 `flex h-full flex-col`；thread 区域 `flex-1 overflow-y-auto p-4`
- 输入区固定底部 `border-t bg-white p-3`
- 移动端：用 `useIsMobile` 切换容器宽度（max-w-3xl vs max-w-2xl）

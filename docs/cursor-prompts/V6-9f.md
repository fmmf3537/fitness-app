## 需求背景（线上抽查发现 ~22% 的 high 档映射是错的）

V6-9c 之后力量类覆盖 92.6%，用户把 `confidence='high'` 的 289 条批量激活为 `active`。
随后抽查 20 条发现 **4 条明显错、3 条有语义丢失**；审核方用规则化扫描复核，66 条命中问题模式。

### 实测错配样例（全部可复现）

| 训记动作 | 现在映射到 | 应该 |
|---|---|---|
| 正手杠铃手腕弯举 | `CURL/BARBELL_BICEPS_CURL` | `CURL/BARBELL_WRIST_CURL`（手腕弯举 ≠ 二头弯举） |
| 弹力带-腿外展 | `BANDED_EXERCISES/EXTERNAL_ROTATION_AT_90_DEGREE_ABDUCTION` | `BANDED_EXERCISES/LEG_ABDUCTION`（腿外展 ≠ 肩外旋） |
| 器械划船1 | `ROW/INDOOR_ROW`（Rowing Machine 有氧划船机） | `ROW/*_ROW` 里的器械/俯身划船项 |
| 吊环弯举 | `SUSPENSION/HAMSTRING_CURL`（腿弯举） | 手臂弯举项，或退回低置信 |
| 上斜哑铃卧推 | `BENCH_PRESS/DUMBBELL_BENCH_PRESS` | `INCLINE_DUMBBELL_BENCH_PRESS` |
| 下斜杠铃卧推 | `BENCH_PRESS/BARBELL_BENCH_PRESS` | `DECLINE_BARBELL_BENCH_PRESS` |
| 单手绳索臂屈伸 | `TRICEPS_EXTENSION/CABLE_LYING_TRICEPS_EXTENSION` | `SINGLE_ARM_*` 项 |

### 根因（已逐条定位，**按这四条改**）

**根因 A：`_exact_bonus` 抵消 `_posture_bonus`，姿态失去决定性**

```python
# 现在
DUMBBELL_BENCH_PRESS         20 + 器械40 + 姿态0  + 完全相等20 = 80
INCLINE_DUMBBELL_BENCH_PRESS 20 + 器械40 + 姿态20 + 完全相等 0 = 80   ← 平局
# 平局后 _finalize 按 (category, name) 字典序 → "D" 在 "I" 前 → 选了不带 incline 的
```

**根因 B：有氧分类混进力量候选池**

`INDOOR_ROW`（Rowing Machine）在 `背` 的部位分类列表里，且其英文名含 `machine`，
于是「器械划船」拿到 60 分排第一，真正的 `BARBELL_ROW` 只有 20 分。

**根因 C：`弯举` / `外展` 词根过宽，且缺具体词**

`手腕弯举`、`环抱弯举` 没有独立词条，退化成 `curl`；`外展` 退化成 `abduction`，
于是肩部 `EXTERNAL_ROTATION_..._ABDUCTION` 命中了腿外展。

**根因 D：`single arm` 与 Garmin 的 `One-arm` 写法不互通**

`_norm("single arm") = "singlearm"`，而 `_norm("One-arm Cable Chest Press") = "onearmcablechestpress"`，
子串不匹配 → 单臂动作全部丢失单臂语义。

CARDIO_ONLY_CATEGORIES: frozenset[str] = frozenset({
    "INDOOR_ROW", "RUN", "RUN_INDOOR", "BIKE_OUTDOOR",
    "ELLIPTICAL", "STAIR_STEPPER", "CARDIO", "LADDER", "FLOOR_CLIMB",
})

# 同名词根在不同部位含义不同：候选名必须含该部位的锚词，否则视为错配
PART_ANCHORED_MOVEMENTS: dict[str, dict[str, tuple[str, ...]]] = {
    # 动作中文关键词 -> {部位: 候选名必须包含的任一英文锚词}

    "内收": {"腿": ("leg", "hip"), "肩": ("shoulder",), "臂": ("shoulder", "arm")},
}

# 中文名里没有限定词时，候选名里出现这些词就判为错配
MOVEMENT_NAME_EXCLUDES: tuple[tuple[str, str, tuple[str, ...]], ...] = (
    # (中文必须含, 中文必须"不含"才生效, 候选名禁止出现的词)
    ("弯举", "腿", ("hamstring",)),
    ("弯举", "手腕", ("wrist",)),
)

> `CARDIO_ONLY_CATEGORIES` 里每个值必须在 `exercises.CATEGORIES` 里，

### 2. `exercise_mapping_candidates.py` 四条规则

#### 规则 A：姿态决定性（改 `_posture_bonus`）

```python
def _posture_bonus(postures: list[str], name_norm: str) -> int:
    """匹配到的姿态 +20/个，**缺失的 −20/个**（各上限 40）。

    姿态词（上斜/下斜/坐姿/俯身/单臂…）是区分 Garmin 变体的关键。原先只加分不加分，
    "Dumbbell Bench Press" 靠 _exact_bonus 的 +20 与 "Incline Dumbbell Bench Press"
    的 +20 打平，最终按字典序选中了不带 incline 的那个。
    """
    if not postures:
        return 0
    hits = sum(1 for p in postures if p and _norm(p) in name_norm)
    misses = sum(1 for p in postures if p and _norm(p) not in name_norm)
    return min(40, hits * 20) - min(40, misses * 20)
```

#### 规则 B：排除有氧分类（改候选池构造）

`pool` 构建后统一过滤一次（**两处池都要过滤**：部位窄化池与全目录回退池）：

```python
pool = [e for e in pool if e.get("category") not in CARDIO_ONLY_CATEGORIES]
```

#### 规则 C：部位锚词 + 中文名排除（新增私有函数，在打分循环内调用）

```python
def _is_inconsistent(
    xunji_name: str, part: str, name_norm: str
) -> bool:
    """候选与动作语义明显不符时返回 True（该候选直接跳过，不给分）。"""
    # 1) 中文名排除：如"弯举"未限定"腿"时不得命中 hamstring
    for must_have, must_not_have, banned in MOVEMENT_NAME_EXCLUDES:
        if must_have in xunji_name and must_not_have not in xunji_name:
            if any(term in name_norm for term in banned):
                return True
    # 2) 部位锚词：外展/内收 必须落在对应部位的英文词上
    for keyword, anchors_by_part in PART_ANCHORED_MOVEMENTS.items():
        if keyword not in xunji_name:
            continue
        anchors = anchors_by_part.get(part)
        if not anchors:
            continue
        if not any(_norm(a) in name_norm for a in anchors):
            return True
    return False
```

调用位置：打分循环内、`mv_norm not in name_norm` 判断之后立刻
`if _is_inconsistent(name, part, name_norm): continue`。

#### 规则 D：`single arm` ↔ `one-arm` 互通（改动作匹配判断）

```python
def _movement_alternatives(mv: str) -> tuple[str, ...]:
    """同一语义的不同英文写法。Garmin 里单臂动作常写作 One-arm / Single-arm。"""
    base = _norm(mv)
    if not base:
        return ()
    alts = {base}
    if "singlearm" in base:
        alts.add(base.replace("singlearm", "onearm"))
    if "onearm" in base:
        alts.add(base.replace("onearm", "singlearm"))
    return tuple(alts)
```

匹配改为「任一 alternative 出现在 `name_norm` 里即命中」。

> `_movement_alternatives` 只在 `movements` 的匹配判断里用，**不要改 `_norm` 本身**
> （`_norm` 还被器械/姿态/反向映射复用）。

#### 不要改

- `_equipment_bonus`（含 +40/+20 规则）
- `_exact_bonus`（仍为 +20）
- `_score_to_confidence` 的阈值（60/40）

- V6-9a 的器械专属分类合并、V6-9c 的「部位未知不缩窄 / 窄化无果回退全目录」

## 开发内容

### 1. `services/exercise_mapping.py` 追加以下函数

```python
def list_mappings(
    session: Session,
    *,
    status: str | None = None,
    confidence: str | None = None,
    verified_level: str | None = None,
    keyword: str | None = None,          # 匹配 xunji_name / garmin_display_name（不区分大小写）
    page: int = 1,
    page_size: int = 50,
) -> dict:
    """分页列表。返回：
    {"items": [...], "total": int, "page": int, "page_size": int, "pages": int}
    每个 item 为 dict：
    {"id","xunji_name","garmin_category","garmin_exercise_name","garmin_display_name",
     "weight_strategy","status","confidence","source","verified_level","mapping_version",
     "not_applicable_reason","note","candidate_count"}
    `candidate_count` = 该动作下 status='pending' 的候选数。
    排序：先按 status 优先级 draft(0) < active(1) < disabled(2) < not_applicable(3)，
          再按 confidence 优先级 high(0) < medium(1) < low(2) < None(3)，
          最后按 xunji_name 升序。
    """


def get_mapping_detail(session: Session, mapping_id: int) -> dict | None:
    """详情：mapping 全字段 + candidates（按 rank 升序，含 accepted/rejected）。"""


def update_mapping(
    session: Session,
    mapping_id: int,
    *,
    garmin_category: str | None = None,
    garmin_exercise_name: str | None = None,
    garmin_display_name: str | None = None,
    weight_strategy: str | None = None,
    status: str | None = None,
    reason: str | None = None,
    actor: str = "user",
    _unset: object = ...,          # 内部哨兵，调用方不要传
) -> dict:
    """部分更新 + 写审计 + mapping_version += 1。

    **只更新显式传入的字段**（用哨兵区分「传 None」与「不传」）。
    - 校验 garmin_category 若给出则必须在 exercises.CATEGORIES 里，否则抛
      `MappingValueError(code="INVALID_CATEGORY")`
    - 校验 garmin_exercise_name 若给出则必须能在目录中找到
      `(category, exercise_name)` 组合（找不到抛 `MappingValueError(code="INVALID_EXERCISE")`）
      —— 注意：允许空串（Garmin 只显示 category 名的条目）
    - 校验 status 若给出必须在 {draft, active, disabled, not_applicable} 里
    - 校验 weight_strategy 若给出必须在 {total, per_hand, bodyweight, assisted} 里
    - 写 `ExerciseMappingAudit`（action='update'，before_json/after_json 为改动快照
      的 JSON 字符串，仅含被改字段）
    - `mapping_version += 1`
    - 返回更新后的 item dict（形状同 list_mappings 的 item）
    """


def activate_mapping(session: Session, mapping_id: int, *, reason: str | None = None,
                     actor: str = "user") -> dict:
    """采纳为 active。校验：garmin_category 不能为空，否则抛
    `MappingValueError(code="MISSING_CATEGORY")`。
    写审计 action='activate'，mapping_version += 1。"""


def disable_mapping(session: Session, mapping_id: int, *, reason: str | None = None,
                    actor: str = "user") -> dict:
    """停用。写审计 action='disable'，mapping_version += 1。"""


def accept_candidate(session: Session, mapping_id: int, candidate_id: int, *,
                     weight_strategy: str | None = None, reason: str | None = None,
                     actor: str = "user") -> dict:
    """采纳指定候选：把候选的 category/exercise_name/display_name 写进 mapping，
    mapping.status='active'，候选 status='accepted'（同 mapping 下其他 pending 候选
    置为 'rejected'），写审计 action='activate'，mapping_version += 1。"""


def batch_activate(session: Session, *, confidence: str = "high",
                   only_confirmed_catalog: bool = True,
                   actor: str = "user") -> dict:
    """把满足条件的 draft 批量转 active。返回 {"activated": n, "skipped": m}。

    条件：status='draft' AND confidence=<confidence> AND garmin_category IS NOT NULL
          AND（only_confirmed_catalog=True 时）Garmin 目录里确实存在该组合。
    每行单独写审计。"""


def search_catalog(*, q: str = "", category: str | None = None,
                   limit: int = 30) -> list[dict]:
    """在 Garmin 离线目录里搜索，返回
    [{"category","exercise","name"}]，供前端「换一个候选」用。
    - q 为空时返回该 category 下前 limit 条
    - 不按 category 过滤时全目录搜
    - limit 上限 100（超出按 100 处理）
    """


def list_stale_syncs(session: Session, *, limit: int = 50) -> list[dict]:
    """找出「已同步但映射已变」的记录。

    对 `garmin_plan_sync` 中 status='synced' 且 mapping_hash 非空的记录：
    取该记录的 plan_ref + training_date 对应的源动作名列表（从 `payload_json` 里
    解析 movements[].name；解析失败则跳过该记录），重算
    `load_mapping_snapshot_hash(session, names)`，与记录里的 mapping_hash 比较，
    不一致则收入结果：
    {"sync_id","plan_ref","training_date","workout_id","workout_schedule_id",
     "stored_hash","current_hash"}
    """


class MappingValueError(ValueError):
    """带机器可读 code 的校验错误。"""
    def __init__(self, code: str, message: str) -> None: ...
```

> `payload_json` 的结构：`garmin_plan_sync.payload_json` 存的是本地 Workout payload，
> 动作名在 `workoutSegments[0].workoutSteps[*].description` 的
> `"{训记动作名}｜源组 ..."` 前缀里，或子步骤的 `description`。
> **实现时请先读 `services/garmin_plan_sync.py` 里写入 payload 的实际结构再解析**，
> 不要臆造。解析不到就跳过该条（宁可少报，不可误报）。

### 2. `api/exercise_mappings.py` 追加端点

**顺序注意**：`/coverage`、`/generate`、`/catalog`、`/stale-syncs`、`/batch-activate`
这些**固定路径必须注册在 `/{mapping_id}` 之前**，否则会被路径参数吃掉。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 列表，query: `status` `confidence` `verified_level` `keyword` `page` `page_size` |
| GET | `/catalog` | 目录搜索，query: `q` `category` `limit` |
| GET | `/stale-syncs` | stale 同步列表，query: `limit` |
| GET | `/{mapping_id}` | 详情（含候选），不存在返回 404 |
| PATCH | `/{mapping_id}` | 部分更新，body: `{garmin_category?, garmin_exercise_name?, garmin_display_name?, weight_strategy?, status?, reason?}` |
| POST | `/{mapping_id}/activate` | 采纳，body: `{reason?}` |
| POST | `/{mapping_id}/disable` | 停用，body: `{reason?}` |
| POST | `/{mapping_id}/candidates/{candidate_id}/accept` | 采纳候选，body: `{weight_strategy?, reason?}` |
| POST | `/batch-activate` | 批量采纳，body: `{confidence?, only_confirmed_catalog?}` |

**错误映射**：
- `MappingValueError` → 422，`detail={"code": exc.code, "message": str(exc)}`
- 记录不存在 → 404，`detail={"code": "MAPPING_NOT_FOUND"}`
- 其余同现有项目风格

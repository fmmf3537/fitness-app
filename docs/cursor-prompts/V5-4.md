## 开发内容

### 1. `services/coach_chat.py` 新建

```python
"""V5-4 AI 教练独立聊天：消息装配 + 幂等 + 成本记账 + memory_section 注入。"""

MAX_CONTENT_LENGTH = 1000      # 单条用户消息上限（沿用 report_chat 常量）
HISTORY_WINDOW = 30            # 独立聊天窗口更大（无报告上下文，保留更多轮）
MAX_MESSAGES_TOTAL = 200       # 整库上限（独立聊天无报告分组，需有总护栏）
COACH_CHAT_SYSTEM_PROMPT = (
    "你是一位专业、亲切的 AI 健身教练。用户正在自由与你聊天："
    "可以问训练相关问题，也可以告诉你他的长期偏好/伤病/目标/忌讳等。"
    "请基于用户的长期记忆（含用户须知、过往对话要点、长期训练统计）"
    "用中文简洁、具体地回答；不要编造数据，不确定时明确说明。"
)
```

导出函数（与 `report_chat.py` 对齐）：

- `build_system_prompt(memory_section: str = "") -> str`
   `COACH_CHAT_SYSTEM_PROMPT` + `memory_section`（空时不附加换行）

- `build_messages(history: list[CoachChatMessage], user_content: str, memory_section: str = "", *, window: int = HISTORY_WINDOW) -> list[dict]`
   `system → history[-window:] → 新 user`

- `post_message(session, content: str, client_request_id: str, *, chat_fn=None) -> tuple[CoachChatMessage, CoachChatMessage]`
   完整流程：
   1. 校验 content 非空且 ≤1000 字 → 否则 raise ValueError
   2. **幂等检查**：按 client_request_id 找已有消息对；命中直接返回
   3. **总护栏**：查询 `count(CoachChatMessage.id) >= MAX_MESSAGES_TOTAL` → raise ChatMessageLimitError
   4. 落库 user 消息（role='user', content, client_request_id）
   5. 计算 memory_section：`compose_memory_section_for(session, {}, 'chat', l3=query_longterm_stats(...))`（try/except 兜底 None）
   6. 拉历史（id < 当前 user_msg.id），按 id 正序 → build_messages
   7. 调 chat_fn（默认 `llm.chat(msgs, session=session, purpose='coach_chat')`）
   8. 落库 assistant 消息（role='assistant', content, model, tokens, cost）
   9. return (user_msg, assistant_msg)

- `list_messages(session, *, limit: int = 200) -> list[CoachChatMessage]`
   按 id 正序返回（最早 → 最新）；limit 默认 200，超过时只返回最新 200 条（不报错，截断即可）

- `clear_messages(session) -> int`
   **hard delete**（独立聊天不像报告有审计需求，保留 V3-11 风格的"软删" 仅用于报告）；返回删除条数

- `ChatMessageLimitError(ReportChatError)` 异常类（与 report_chat 一致）

### 2. `api/coach_chat.py` 新建

```python
router = APIRouter(prefix="/api/coach/chat", tags=["coach-chat"], dependencies=[Depends(require_auth)])
```

- `POST /api/coach/chat`
   body: `{content: str, client_request_id: str}`
   → 调 `services.coach_chat.post_message`
   → 200 `{user_message: {...}, assistant_message: {...}}`（与 report_chat.post_message 形态一致）
   → 400 ValueError；409 ChatMessageLimitError

- `GET /api/coach/chat`
   → 调 `list_messages`，返回 `{messages: [{id, role, content, model, prompt_tokens, completion_tokens, cost_estimate, created_at}]}`
   **不返回 client_request_id**（前端不需要）

- `DELETE /api/coach/chat`
   → 调 `clear_messages`，返回 `{ok: true, deleted: N}`

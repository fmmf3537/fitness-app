## 需求背景（方案见 `docs/EXERCISE-MAPPING-PLAN.md` §5）

Garmin 写入依赖 `garmin_workout_mapper.EXERCISE_WHITELIST`（硬编码 16 条），而训记标准动作表
有 1091 个。计划一换动作就 422 整日禁止同步。

本切片**只做地基**：把映射从硬编码搬到 DB，为后续「全量生成 + 分级激活 + 纠错」铺路。
**本切片不生成任何新映射**（那不是 V6-1 的职责，属 V6-2/V6-7），也不改任何现有行为。

### 1. `models.py` 新增 3 个模型 + 1 列

追加到文件末尾（`WorkoutSetHr` / `GarminPlanSync` 等既有模型之后），风格与既有模型一致
（SQLAlchemy 2.x `Mapped` / `mapped_column`，`server_default=func.now()`）：

```python
class ExerciseMapping(Base):
    """训记动作 → Garmin 动作映射（全量 1091 行，分级激活）。"""

    __tablename__ = "exercise_mapping"
    __table_args__ = (
        UniqueConstraint("xunji_name", name="uq_exercise_mapping_xunji_name"),
    )

    id: Mapped[int] = mapped_column(primary_key=True)
    xunji_name: Mapped[str] = mapped_column(String(200))
    garmin_category: Mapped[str | None] = mapped_column(String(64))
    garmin_exercise_name: Mapped[str | None] = mapped_column(String(128))
    garmin_display_name: Mapped[str | None] = mapped_column(String(200))
    # total / per_hand / bodyweight / assisted；仅作语义声明，本切片不做换算
    weight_strategy: Mapped[str | None] = mapped_column(String(32))
    # draft / active / disabled / not_applicable
    status: Mapped[str] = mapped_column(String(20), default="draft")
    not_applicable_reason: Mapped[str | None] = mapped_column(String(100))
    confidence: Mapped[str | None] = mapped_column(String(10))
    source: Mapped[str | None] = mapped_column(String(20))
    # none / catalog / created / displayed
    verified_level: Mapped[str | None] = mapped_column(String(20))
    verified_at: Mapped[datetime | None] = mapped_column(DateTime)
    mapping_version: Mapped[int] = mapped_column(Integer, default=1, server_default="1")
    note: Mapped[str | None] = mapped_column(Text)
    created_at: Mapped[datetime] = mapped_column(DateTime, server_default=func.now())
    updated_at: Mapped[datetime] = mapped_column(
        DateTime, server_default=func.now(), onupdate=func.now()
    )


class ExerciseMappingCandidate(Base):
    """待复核映射候选（V6-2/V6-3 写入，本切片只建表）。"""

    __tablename__ = "exercise_mapping_candidate"

    id: Mapped[int] = mapped_column(primary_key=True)
    xunji_name: Mapped[str] = mapped_column(String(200))
    garmin_category: Mapped[str] = mapped_column(String(64))
    garmin_exercise_name: Mapped[str | None] = mapped_column(String(128))
    garmin_display_name: Mapped[str | None] = mapped_column(String(200))
    confidence: Mapped[str | None] = mapped_column(String(10))
    reason: Mapped[str | None] = mapped_column(Text)
    rank: Mapped[int | None] = mapped_column(Integer)
    status: Mapped[str] = mapped_column(String(20), default="pending")
    created_at: Mapped[datetime] = mapped_column(DateTime, server_default=func.now())
    resolved_at: Mapped[datetime | None] = mapped_column(DateTime)


class ExerciseMappingAudit(Base):
    """映射变更审计（纠错留痕）。"""

    __tablename__ = "exercise_mapping_audit"

    id: Mapped[int] = mapped_column(primary_key=True)
    mapping_id: Mapped[int] = mapped_column(Integer)
    xunji_name: Mapped[str] = mapped_column(String(200))
    action: Mapped[str] = mapped_column(String(20))  # create/update/activate/disable/reactivate
    before_json: Mapped[str | None] = mapped_column(Text)
```

```python
    """
```

### 4. `garmin_workout_mapper.py` 改 2 处 + 加 1 个 issue code

**a. `map_plan_day` 加 keyword-only 参数**：

```python
def map_plan_day(
    plan_day: dict[str, Any],
    *,
    plan_ref: str | None = None,
    mappings: dict[str, dict[str, Any]] | None = None,
) -> dict[str, Any]:
    """...
    `mappings` 为 None 时回退 `EXERCISE_WHITELIST`（保持既有调用与测试完全不变）。
    """
    active_mappings = mappings if mappings is not None else EXERCISE_WHITELIST
```

L304 的 `EXERCISE_WHITELIST.get(name)` 改为 `active_mappings.get(name)`。

**b. 新增「有映射但未激活」的区分**：

`mappings` 注入的条目可能带 `status` 字段（来自 DB）。当 `status` 存在且不是 `'active'` 时，
产出一个**新的 issue code**，与「完全没映射」区分开：

```python
"code": "MAPPING_NOT_APPROVED",
"movement": name,
"message": f"{name}：映射尚未复核确认（当前 {status}）",
```

判定顺序：先在 `active_mappings` 里查不到 → `UNKNOWN_EXERCISE`（保持原行为，文案不变）；
查到了但 `status not in (None, 'active')` → `MAPPING_NOT_APPROVED`；
`status` 为 `None` 或 `'active'` → 正常映射（`EXERCISE_WHITELIST` 的条目没有 `status` 键，
必须继续正常工作）。

**c. `expand_workout` 同样加注入参数**：

```python
def expand_workout(
    payload: dict[str, Any],
    *,
    mappings: dict[str, dict[str, Any]] | None = None,
) -> list[dict[str, Any]]:
```

L507 的反向表改为基于 `mappings if mappings is not None else EXERCISE_WHITELIST` 构建。
**必须保留**既有两行特例（P2/P3 实测的规范化别名）：

```python
reverse[("BENCH_PRESS", "")] = "器械推胸"
reverse[("LATERAL_RAISE", "")] = "侧平举"
```

> 注意：反向表构建时若同一个 `(category, exerciseName)` 对应多个训记名，后写覆盖先写——
> 保持现有 dict comprehension 行为即可，不要新增去重逻辑（避免改变既有语义）。

#### 导出 API

```python
@dataclass(frozen=True)
class Candidate:
    xunji_name: str
    garmin_category: str
    garmin_exercise_name: str      # 可为空串
    garmin_display_name: str
    confidence: str                # "high" / "medium" / "low"
    rank: int                      # 1 = 主推
    reason: str                    # 中文，说明命中依据


def classify_applicability(xunji_name: str) -> tuple[bool, str | None]:
    """返回 (可映射为力量训练?, 不可映射原因)。
    - CARDIO_KEYWORDS 命中 → (False, "有氧动作，非力量训练")
    - FLEXIBILITY_KEYWORDS 命中 → (False, "拉伸/放松动作，非力量训练")
    - 否则 (True, None)
    命中顺序：先 CARDIO 后 FLEXIBILITY（与 stats._PART_KEYWORDS 的优先级精神一致）。
    """


def extract_tokens(xunji_name: str) -> dict[str, list[str]]:
    """抽取 {equipment: [...], postures: [...], movements: [...], part: str}。
    - 长键优先（同一位置命中更长的词后不再重复计入短词）
    - 允许一个动作名同时含多个 posture（如「上斜单臂哑铃卧推」）
    - movements 取命中列表，可能多个（如「哑铃卧推飞鸟」）
    """


def generate_candidates(
    xunji_name: str,
    *,
    limit: int = 3,
    catalog: list[dict[str, str]] | None = None,

    """4 级窄化生成候选，按 rank 升序返回最多 limit 条。
    `catalog` 为 None 时用 `exercises.EXERCISES`（可注入以便单测）。
    """


def generate_batch(
    names: list[str],
    *,
    limit: int = 3,
) -> dict[str, list[Candidate]]:
    """批量版；对每个名字调用 generate_candidates。"""
```

#### 算法规格（**必须严格按此实现，便于单测**）

**第 0 步 · 适用性**：`classify_applicability` 返回 `False` 时，`generate_candidates`
直接返回**空 list**（该动作由 V6-7 标 `not_applicable`，不产候选）。

**第 1 步 · 部位缩窄**：`part = classify_part(name)`；
`categories = PART_TO_GARMIN_CATEGORIES.get(part) or []`；
若 `categories` 为空 → 不缩窄（用全目录）。

**第 2 步 · 词元抽取**：`extract_tokens(name)` 得到 equipment / postures / movements。

**第 3 步 · 硬过滤 + 打分**：

- 若 `movements` 为空 → 走**兜底路径**（见第 4 步），跳过本步。
- 否则，对每个 `movement` 英文词根 `mv`，遍历 catalog 中 `category in categories`
  （categories 为空时遍历全部）的条目：
  - **硬条件**：`mv` 必须在 `entry["name"].lower()` 里出现；否则跳过
  - **基础分**：`20`
  - **动作命中**：已满足（+0）
  - **器械命中**：`equipment` 的英文词根出现在 name 里 → `+40`；
    若 `equipment` 为空串（自重类）且 name 里**不含**任何其它器械词根 → `+20`
  - **姿态命中**：每个 posture 出现在 name 里 → `+20`，**上限 +40**
  - **额外加分**：name 与 `f"{equip} {mv}"` 完全相等（忽略大小写与多余空格）→ `+20`
- 同一 `(category, exercise)` 可能被多个 movement 命中：取**最高分**，不要重复出条目。

**第 4 步 · 兜底路径**（无 movement 词或硬条件全落空）：
- 在 `categories` 内找 `exercise` 为空串的条目（Garmin 只显示 category 名），
  优先 `category` 与部位最贴近者；
- 若仍无 → 返回空 list。

**第 5 步 · 置信度与截断**：

| 分数 | confidence |
|---|---|
| `>= 80` | `high` |
| `50 ~ 79` | `medium` |
| `< 50`（含兜底路径） | `low` |

- 按分数降序、同分按 `category, name` 字典序升序排序
- 取前 `limit` 条，`rank` 从 1 开始
- `reason` 必须可读，格式示例：
  `f"部位={part}；器械={equip or '无'}；动作={mv}；命中 {score} 分"`

**边界要求**：
- `limit <= 0` → 返回空 list
- 空字符串 / 纯空白名 → 返回空 list，不抛异常
- 同名条目在 catalog 里重复出现 → 去重（按 `(category, exercise)`）

## 已核实的关键事实（实读代码，可直接采信）

### 后端接口（V4-3 已交付，形状以此为准）

- `GET /api/skinfold/methods` →
  ```json
  {"methods": [{"key": "jp3_male", "name_zh": "Jackson-Pollock 3 点（男）",
                "sites": [{"key": "chest", "name_zh": "胸"}, ...],
                "sex": "male"|"female"|null, "self_test": "yes"|"assist"|"no"}],
   "profile": {"gender": "male"|"female"|null, "birth_date": "YYYY-MM-DD"|null}}
  ```
  4 个 method：jp3_male（胸/腹/大腿）、jp3_female（肱三头/髂前上棘/大腿）、
  dw4（肱二头/肱三头/肩胛下/髂前上棘）、jp7（7 部位）。
- `POST /api/skinfold/records`：body `{date, method, sites: {site: mm}, note?}` →
  200 `{"record": {..., "bodyfat_result": 13.61, "sites": {...}}, "body_metric": {...}}`；
  400 时 body 为 FastAPI `{"detail": "中文原因"}`（mm 越界/缺部位/缺设置/性别不符）。
  同日同 method 幂等 upsert。
- `GET /api/skinfold/records?method=<key>` → `{"records": [...]}`（**日期倒序**，第一条即最近一次；
  record 含 `date`/`method`/`sites`(dict)/`bodyfat_result`/`note`）。
- `GET /api/settings/profile` → `{"gender": ..., "birth_date": ...}`（未设置为 null）。
- `PUT /api/settings/profile`：body `{gender?, birth_date?}`（PATCH 语义，至少传一个）→
  200 `{"gender":..., "birth_date":...}`；400 `{"detail": ...}`。

### 前端现状

- API 工具：`frontend/src/api/client.js` 的 `api(path, options)` 自动带 token、
  非 ok 抛 `ApiError(status, message)`——**注意：`api()` 不提取 400 的 detail 文案**
  （只有 `apiForm` 提取）。因此非法输入的「明确提示」必须由**前端提交前校验**承担
  （mm 范围 2~60、部位必填），服务端 400 兜底时显示 `err.detail || '提交失败，请检查输入'`。
- `frontend/src/pages/SettingsPage.jsx`：卡片式 section 布局（`rounded-lg border … shadow-sm`），
  error/message 顶部横幅，data-testid 风格齐全。

  （按钮切换 showImport + 内嵌 `<BodyImageImport onImported={…}/>`），
  `load()` 刷新 records；`todayStr()` 工具在本文件。

## 开发内容

### 1. `SkinfoldPanel.jsx`（新组件）

Props：`onSaved?: () => void`（保存成功后回调，父级刷新身体数据）。

- 挂载时 `GET /api/skinfold/methods`；加载失败显示错误。
- **缺资料引导**：`profile.gender` 或 `profile.birth_date` 为 null → 显示琥珀色引导条
  （data-testid="skinfold-profile-guide"）：「皮脂钳测量需要性别与出生日期，请先到设置页「个人资料」填写」，
  表单整体禁用。
- **方案排序**：`profile.gender === 'male'` → jp3_male 为推荐方案置顶；`'female'` →
  jp3_female 置顶；未设置 → 默认顺序。推荐方案卡直接展示；其余 3 个收进
  「更多方案」折叠区（data-testid="more-methods" 切换按钮）。
- **方案卡**（每个 method 一张，radio 式单选，data-testid=`method-card-{key}`）：
  name_zh + 自测标注（yes→`✅ 可自测` / assist→`⚠️ 部分需辅助` / no→`❌ 需辅助`，
  data-testid=`self-test-{key}`）+ 部位中文名列表。
- **表单**（选中方案后展示）：日期（默认今天）、该方案每个部位一个 number 输入
  （label 用中文名，placeholder `mm`，data-testid=`site-input-{siteKey}`）、备注（可选）。
- **上次值回显**：选中方案变化时 `GET /api/skinfold/records?method={key}`，
  有记录则：各部位输入框预填最近一次 sites 值，并显示
  `上次测量：{date} · 体脂率 {bodyfat_result}%`（data-testid="last-record"）；无记录不显示。
- **提交前校验**：部位全部填写、每个数值 ∈ [2, 60]，否则行内中文错误（role="alert"），不发请求。
- 提交 `POST /api/skinfold/records`：成功显示
  `已保存 · 体脂率 {bodyfat_result}%（已写入身体数据）`（data-testid="skinfold-success"），
  刷新上次值并调用 `onSaved`；失败显示 `err.detail || '提交失败，请检查输入（mm 范围 2~60）'`。
- 样式沿用现有卡片/按钮 Tailwind 风格（参考 BodyImageImport/录入指标表单）。

### 2. `SettingsPage.jsx` 加「个人资料」section

- 放在 LLM Key 配置 section 之前（最上方，h1 与横幅之下）。
- 挂载时 `GET /api/settings/profile`；表单：性别 select（`男`=`male` / `女`=`female`，
  data-testid="profile-gender"）、出生日期 date input（data-testid="profile-birth-date"）、
  保存按钮（data-testid="profile-save"）。
- 保存 `PUT /api/settings/profile`（两个字段一起传）；成功复用页顶 message 显示
  「个人资料已保存」；失败显示 err.detail || err.message。
- 加载失败不阻塞设置页其他 section（局部错误即可）。
- 一行说明文案：「性别与出生日期用于皮脂钳体脂率等公式计算，录入一次即可」。

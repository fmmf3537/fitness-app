### 1. 后端 `backend/app/api/ai_reports.py`（_serialize_report 增加字段）

在 `_serialize_report` 内，return dict 增加 `memory_refs` 字段。**实现要点**：

```python
def _serialize_report(session: Session, report: AIReport) -> dict:
    workout = session.get(Workout, report.workout_id) if report.workout_id else None
    # ...既有字段...
    
    # V5-7：解析本次实际注入的记忆条数（不调 LLM，重算 compose_memory_section_for 拿 l1/l2/l3 计数）
    memory_refs = {"l1_count": 0, "l2_count": 0, "l3_count": 0}
    try:
        from app.services.memory_distill import compose_memory_section_for
        from app.services.coach_memory import build_memory_section
        # 锚点同 generator：session_review 用 workout.date；其它用 period_start
        anchor = workout.date if workout else report.period_start
        report_type = report.type or "session_review"
        # 复用现有 l3 注入逻辑
        try:
            from app.services.longterm_stats import query_longterm_stats
            if report_type in ("weekly", "monthly"):
                from app.services.longterm_stats import filter_period_l3
                l3 = filter_period_l3(query_longterm_stats(session, anchor))
            else:
                l3 = query_longterm_stats(session, anchor)
        except Exception:
            l3 = None
        # 取 list_preferences / search_memory 列表大小（与 compose_memory_section_for 内部一致）
        from app.services.coach_memory import list_preferences, search_memory
        from app.services.memory_distill import build_query_tags
        prefs = list_preferences(session, active_only=True)
        wd = {"date": anchor.isoformat(), "movements": [], "tags": None} if workout else {"date": anchor.isoformat(), "movements": [], "tags": None}
        # 简化：workout_dict 重建太繁；直接取 l1/l2/l3 三段计数
        l1_count = len([p for p in prefs if p.content])
        # l2：与 generator 同样的 query_tags 聚合后 search_memory（V5-2 已实现）
        tags = build_query_tags(wd, report_type) if workout else [report_type]
        memories = search_memory(session, tags, limit=5)
        l2_count = len([m for m in memories if m.summary])
        # l3：dict 长度（仅在 non-None 时计数）
        l3_count = len(l3) if isinstance(l3, dict) else 0
        memory_refs = {"l1_count": l1_count, "l2_count": l2_count, "l3_count": l3_count}
    except Exception as exc:  # 解析失败兜底
        logger.warning("V5-7 memory_refs 解析失败：%s", exc)
    
    return {
        # ...既有字段...
        "memory_refs": memory_refs,
    }
```

**简化版（推荐）**：直接复用 `compose_memory_section_for` 返回的字符串，按 `build_memory_section` 的 section 标记解析：

```python
from app.services.memory_distill import compose_memory_section_for
# workout_dict 构造
wd = {"date": anchor.isoformat(), "movements": [], "tags": None}
section = compose_memory_section_for(session, wd, report_type)
# 解析 section（已知格式：## 用户长期记忆（AI 参考）\n须知：\n- ...\n历史对话要点：\n- ...\n长期统计：\n- ...）
l1_count = section.count("\n须知：\n") and (section.split("\n须知：\n", 1)[1].split("\n历史对话要点：", 1)[0].count("\n- ") if "\n历史对话要点：" in section else 0) or 0
# 简化：直接 re
import re
l1_match = re.search(r"须知：\n((?:- .+\n)*)", section)
l2_match = re.search(r"历史对话要点：\n((?:- .+\n)*)", section)
l3_match = re.search(r"长期统计：\n((?:- .+\n)*)", section)
memory_refs = {
    "l1_count": l1_match.group(1).count("\n- ") if l1_match else 0,
    "l2_count": l2_match.group(1).count("\n- ") if l2_match else 0,
    "l3_count": l3_match.group(1).count("\n- ") if l3_match else 0,
}
```

`compose_memory_section_for` 内部已 catch 所有异常返回 `""`，所以**外部不需要 try/except 兜底**（除非要写日志）。

**最终简化实现**（Cursor 自选其一）：

- 方案 A：用 re 解析 `compose_memory_section_for` 返回的字符串
- 方案 B：分别调 `list_preferences / search_memory / query_longterm_stats` 拿长度（更直接，但稍多代码）

**Cursor 自己选最干净的方案**，但要满足：
- `memory_refs` 字段总是返回（l1_count/l2_count/l3_count 三个键都在，int 值）
- 不调 LLM（这是性能红线）
- 现有 `_serialize_report` 调用点不变（向后兼容，前端只是新增字段）

## 实施内容

### 1. `GarminPlanPreviewModal.jsx`

**a. 顶部 import 增加一行**（与既有 ui 组件 import 风格一致）：
```js
import ConfirmDialog from './ui/ConfirmDialog'
```

**b. 组件内新增状态**（放在既有 state 声明附近，例如 `submitting` 旁边）：
```js
const [confirmOpen, setConfirmOpen] = useState(false)
```

**c. 新增一个「请求确认」函数**（放在 `handleConfirm` **之前**）：
```js
const requestConfirm = () => {
  if (!canWrite || submitting || confirmOpen) return
  setConfirmOpen(true)
}
```

**d. 确认框确认后**：
```js
const handleDialogConfirm = () => {
  setConfirmOpen(false)
  void handleConfirm()
}
```
`handleConfirm` 本体**完全保持原样**（不要加 confirm 逻辑进去）。

**e. 按钮改为触发确认**：把 L~408 的 `onClick={handleConfirm}` 改为 `onClick={requestConfirm}`，
其余属性（`variant` / `fullWidth` / `disabled` / `testId` / 子节点）**全部不变**。

**f. 渲染 ConfirmDialog**：在 `return createPortal(` 的最外层容器内、
既有内层弹窗 `</div>` **之后**（作为兄弟节点），加：

```jsx
<ConfirmDialog
  open={confirmOpen}
  title={isReschedule ? '确认顺延改期？' : '确认写入 Garmin？'}
  description={confirmDescription}
  confirmText={isReschedule ? '确认改期' : '确认写入'}
  cancelText="取消"
  danger
  onConfirm={handleDialogConfirm}
  onCancel={() => setConfirmOpen(false)}
/>
```

**g. `confirmDescription` 按场景给出具体后果**（在组件内定义，放在 `handleConfirm` 附近）：

| 场景 | 文案 |
|---|---|
| `isReschedule` | `将从 ${preview?.from_date} 顺延到 ${preview?.to_date}，保留原 Workout ${sync?.workout_id || '—'} 与日程 ${sync?.workout_schedule_id || '—'} 的关联。` |
| 非顺延 + `status === 'update_available'` | `将覆盖此应用管理的 Garmin 训练（保留原 Workout 与日程关联），日期 ${dayDate}。` |
| 非顺延 + `status === 'failed'` | `将从已保存的阶段恢复，系统会先对账，不会重复创建。日期 ${dayDate}。` |
| 其余（新建） | `将在 Garmin Connect 为 ${dayDate} 创建训练并安排日程。Garmin 不支持批量删除，误创建需在 App 中手动删除。` |

> 日期变量名以组件内实际 props 为准（读源码确认 `dayDate` / `targetDate` / `preview.from_date` 等的用法），不要臆造。
> 文案里不要出现 URL、token 或内部 ID 以外的敏感信息。

**h. 关闭外层弹窗时复位**：`onClose` 或 `open` 变为 false 时把 `confirmOpen` 置回 false，
避免下次打开时确认框残留。**最小改法**：在既有的 `if (!open) return null` 之前加
```js
if (!open) { if (confirmOpen) setConfirmOpen(false); return null }
```
（注意 React 不允许在 render 里 setState 导致循环——若判断有风险，改用 `useEffect(() => { if (!open) setConfirmOpen(false) }, [open])`，
**由你选一个不会触发无限渲染的写法**。）

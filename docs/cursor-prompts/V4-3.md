## 数据模型（models.py）

```python
class SkinfoldRecord(Base):
    """皮脂钳测量记录（V4-3）：同日同 method 幂等 upsert。"""

    __tablename__ = "skinfold_record"
    __table_args__ = (UniqueConstraint("date", "method", name="uq_skinfold_record_date_method"),)

    id: Mapped[int] = mapped_column(primary_key=True)
    date: Mapped[date] = mapped_column(Date)
    method: Mapped[str] = mapped_column(String(20))  # jp3_male / jp3_female / dw4 / jp7
    sites_json: Mapped[str] = mapped_column(Text)    # {"chest": 10.0, ...} 单位 mm
    density: Mapped[float] = mapped_column(Float)    # 身体密度 g/cm³
    bodyfat_result: Mapped[float] = mapped_column(Float)  # 体脂率 %（round 2 位）
    note: Mapped[str | None] = mapped_column(Text)
    created_at: Mapped[datetime] = mapped_column(DateTime, server_default=func.now())
    updated_at: Mapped[datetime] = mapped_column(DateTime, server_default=func.now(), onupdate=func.now())
```

## 公式（services/skinfold.py）

- Siri 公式（四方案共用）：`bodyfat% = (4.95 / density − 4.5) × 100`
- Jackson-Pollock 3 点（男，sites = chest/abdomen/thigh，sum = 部位和）：
  `D = 1.10938 − 0.0008267·sum + 0.0000016·sum² − 0.0002574·age`
- Jackson-Pollock 3 点（女，triceps/suprailiac/thigh）：
  `D = 1.0994921 − 0.0009929·sum + 0.0000023·sum² − 0.0001392·age`
- Jackson-Pollock 7 点（chest/midaxillary/triceps/subscapular/abdomen/suprailiac/thigh）：
  - 男：`D = 1.112 − 0.00043499·sum + 0.00000055·sum² − 0.00028826·age`
  - 女：`D = 1.097 − 0.00046971·sum + 0.00000056·sum² − 0.00012828·age`
- Durnin-Womersley 4 点（biceps/triceps/subscapular/suprailiac，`L = log10(sum)`，
  `D = c0 − c1·L`，系数按性别+年龄带；年龄 <17 按 17-19 带）：

| 年龄带 | 男 c0 / c1 | 女 c0 / c1 |
|---|---|---|
| 17-19 | 1.1620 / 0.0630 | 1.1549 / 0.0678 |
| 20-29 | 1.1631 / 0.0632 | 1.1599 / 0.0717 |
| 30-39 | 1.1422 / 0.0544 | 1.1423 / 0.0632 |
| 40-49 | 1.1620 / 0.0700 | 1.1333 / 0.0612 |
| 50+ | 1.1715 / 0.0779 | 1.1339 / 0.0645 |

服务层接口：

```python
METHODS: dict[str, dict]  # method → {"name_zh": str, "sites": list[str],
                          #          "sex": "male"|"female"|None, "self_test": "yes"|"assist"|"no"}
class SkinfoldValidationError(ValueError): ...

def compute_bodyfat(method, sites: dict[str, float], *, gender: str, age: int) -> tuple[float, float]:
    """返回 (density, bodyfat%)，bodyfat 保留 2 位小数。
    校验（失败抛 SkinfoldValidationError，中文消息）：
    method 合法；部位齐全且每个 mm ∈ [2,60]；gender ∈ {male, female}；age ∈ [10,120]；
    jp3_male 要求 gender=male，jp3_female 要求 gender=female；dw4/jp7 按 gender 选系数。"""

def upsert_skinfold_record(session, day: date, method: str, sites: dict, note=None) -> SkinfoldRecord:
    """从 settings 单行读 gender/birth_date（缺失抛 SkinfoldValidationError，
    消息明确提示'请先在设置页填写性别/出生日期'）；按测量日期算 age；
    compute_bodyfat；按 (date, method) 幂等 upsert；随后复用
    body_metrics_service.upsert_body_metric 写 type='bodyfat'（note 注明来源如
    '皮脂钳 Jackson-Pollock 3 点（男）'）。整体一个事务。"""

def query_skinfold_records(session, method=None, day=None) -> list[SkinfoldRecord]  # 日期倒序
def to_dict(row) -> dict  # sites_json 反序列化为 dict 输出
```

`METHODS` 元数据（供 /methods 端点与后续前端 V4-4 使用）：
- `jp3_male`：`Jackson-Pollock 3 点（男）`，sites=[chest, abdomen, thigh]，sex=male，self_test="yes"
- `jp3_female`：`Jackson-Pollock 3 点（女）`，sites=[triceps, suprailiac, thigh]，sex=female，self_test="assist"
- `dw4`：`Durnin-Womersley 4 点`，sites=[biceps, triceps, subscapular, suprailiac]，sex=None，self_test="no"
- `jp7`：`Jackson-Pollock 7 点`，sites=[chest, midaxillary, triceps, subscapular, abdomen, suprailiac, thigh]，sex=None，self_test="no"

部位 key 中文名一并放元数据（前端回显用）：chest=胸、abdomen=腹、thigh=大腿、triceps=肱三头、
suprailiac=髂前上棘、biceps=肱二头、subscapular=肩胛下、midaxillary=腋中。

## API（api/skinfold.py，prefix `/api/skinfold`，router 级 dependencies=[Depends(require_auth)]）

- `GET /api/skinfold/methods` → `{"methods": [METHODS 元数据含 sites 中文名], "profile": {"gender":..., "birth_date":...}}`
  （profile 从 settings 单行读，未设置则为 null，前端据此提示先填设置）
- `POST /api/skinfold/records`：body `{date, method, sites: {site: mm}, note?}`；
  调 `upsert_skinfold_record`；`SkinfoldValidationError` → 400（消息透传）；
  返回 `to_dict(record)` + `"body_metric": body_metrics_service.to_dict(...)` 写入结果。
- `GET /api/skinfold/records?method=&date=` → `{"records": [...]}`（日期倒序）。

settings.py 新增（同文件追加，不动既有 LLM 端点）：
- `GET /api/settings/profile` → `{"gender": str|null, "birth_date": "YYYY-MM-DD"|null}`
- `PUT /api/settings/profile`：body `{gender?, birth_date?}`；校验 gender ∈ {male, female}、
  birth_date 为合法 ISO 日期且推算年龄 ∈ [10,120]；settings 单行不存在则创建；
  只允许更新传入的字段（PATCH 语义），返回更新后 profile。

main.py：import 并 `app.include_router(skinfold_router)`（放在 body_metrics_router 之后即可）。

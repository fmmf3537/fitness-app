### 2. 动作组次渲染加语义 + 有效负荷折算（`build_session_review_prompt`）

- workout dict 新增可选键 `body_weight`（float 或 None；缺省视为 None，不破坏现有调用）。
- 动作组次段（约 380-405 行）改造：`exetype = _normalize_exetype(mv.get("exetype"))`，逐组渲染：
  - `help`：`  - 第{i}组：辅助 {weight}{unit} × {reps}`；
    若 `body_weight` 非 None 且 weight 可转 float，追加 `（有效负荷 {round(body_weight - weight, 1)}kg）`
    （有效负荷 = 体重 − 辅助，可为负数，如实输出）。
  - `plus_weight`：`  - 第{i}组：负重 +{weight}{unit} × {reps}`；
    同上条件追加 `（有效负荷 {round(body_weight + weight, 1)}kg）`。
  - 其他/空：维持现有 `{weight}{unit} × {reps}` 输出不变。
  - RPE / 【未完成】 / reps-only / 数据缺失 等既有分支逻辑保持原样，语义前缀只作用于
    「weight+reps 都有」的分支。
  - `body_weight` 为 None 时：只有语义前缀、无折算（降级，不报错不造数）。

### 3. `query_movement_history` 按 exetype 分组

- 签名加 keyword-only 参数 `exetype: str | None = None`（默认 None = 匹配 exetype 为空/缺失的动作，
  即普通动作组；传 `"help"`/`"plus_weight"` 匹配对应组）。匹配时用 `_normalize_exetype(mv.get("exetype"))`
  与 `_normalize_exetype(exetype)` 比较。
- 返回 dict 增加 `"exetype"` 键（回传归一化后的值），其余结构与统计逻辑不变——PR 与容量
  自然在组内计算（因为查询已按组过滤）。
- 有效负荷折算进历史明细：当组为 `help`/`plus_weight` 时，对每条 recent 记录调
  `query_body_weight(session, 该记录日期)`，算出 `effective_load = round(体重 ∓ best_weight, 1)`
  （help 用减、plus_weight 用加），写入 recent 记录 `"effective_load"` 键；无体重记录该键为 None。
  普通组不加此键（或恒 None，二选一，保持一致即可）。

### 4. 历史段渲染（`build_session_review_prompt` 约 439-458 行 else 分支）

- recent 行按 `hist.get("exetype")` 加语义：
  - help：`  - {date}：最佳 辅助 {best_weight}kg × {best_reps}，总容量 …`；
    `effective_load` 非 None 时该行追加 `（有效负荷 {x}kg）`。
  - plus_weight：`最佳 负重 +{best_weight}kg × …`；同上追加有效负荷。
  - 空：维持现有格式逐字节不变。
- PR 行 `- 个人纪录（PR）重量：{pr} kg`：help 组改为 `- 最大辅助重量：{pr} kg（辅助重量越大越省力，勿与负重直接比较）`；
  plus_weight 组改为 `- 个人纪录（PR）负重：+{pr} kg`；普通组不变。

### 5. `generate_session_review` 接线（约 534-540 行）

- 历史循环改为按 (name, exetype) 分组查：

```python
seen: set[tuple[str, str]] = set()
for mv in movements:
    name = (mv.get("name") or "").strip()
    if not name:
        continue
    exetype = _normalize_exetype(mv.get("exetype"))
    if (name, exetype) in seen:
        continue
    seen.add((name, exetype))
    key = name if not exetype else f"{name}（{EXETYPE_ZH.get(exetype, exetype)}）"
    history[key] = query_movement_history(session, name, workout.date, exetype=exetype)
```

- 取 `body_weight = query_body_weight(session, workout.date)` 写入 `workout_dict["body_weight"]`。

   `effective_load`；无体重记录时该键为 None。
5. **generate_session_review 集成**：movements 同时含 help 与 plus_weight 同名动作时，
   chat_fn 捕获的 prompt 中 `## 引体向上（辅助）` 与 `## 引体向上（负重）` 两个小节都在，
   且 PR 不被辅助重量污染。

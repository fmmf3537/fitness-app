## 已核实的关键事实（实读代码，可直接采信）

### 后端接口（V4-5 已交付，形状以此为准）

- `POST /api/ai-reports/session_review/{workout_id}/regenerate_with_feedback` →
  200 `{"report": {...}}`（序列化报告，含 content_md/one_liner/score）；
  404 workout 不存在；**429 当日重生成超 5 次**（detail 中文）。
- `POST /api/ai-reports/next_advice/{workout_id}/regenerate_with_feedback` →
  同上；**404 该训练暂无下次建议；422 无训记计划缓存（旧报告已删）**。
- 两接口同步执行（LLM 调用耗时数秒到几十秒属正常，按钮须 loading 态）。
- **注意**：`api()`（client.js）对 4xx 只给 `err.status` 与通用 message，**不提取
  detail 文案**——按 status 映射固定中文提示即可（429→「今日重生成次数已达上限（5 次），明天再来」；
  422→「无训记计划缓存，暂时无法生成下次建议」；404→「无法重新生成：记录不存在」）。

### 前端现状

- `SessionReviewSection.jsx`（44 行）：按 `date+type=session_review` 拉报告、find
  `workout_id` 匹配，`report` state；无报告不渲染；头部右侧挂
  `<SharePosterButton report={report} workout={workout} />`。
- `NextAdviceSection.jsx`：`type=next_advice` 同款拉取；无报告显示「暂无下次训练建议」。
- `ReportChatSection.jsx`：prop `reportId`；内部折叠入口（`chat-expand-btn`）→ 展开拉
  `GET /api/ai-reports/{reportId}/messages`；**reportId 变化时组件自动重置对话状态**
  （useEffect 监听 reportId）。重生成后旧报告被删、新报告 id 不同——直接以新
  `report.id` 渲染，对话区自然重置（旧对话已被消费注入新点评，符合预期）。
- `SharePosterButton`：点击时才按 `report.id` 拉 `/api/posters/data`——report prop 更新即
  自动用新数据；**为它加 `key={report.id}` 可在重生成后强制关掉旧预览弹层**（海报预览刷新）。
- `WorkoutDetailPage.jsx:171-172`：`<SessionReviewSection workout={workout} />` 与
  `<NextAdviceSection workout={workout} />` 并列——本切片**不需要改页面**。

## 开发内容

### 1. `SessionReviewSection.jsx`

- 正文 `<SimpleMarkdown>` 之后渲染 `<ReportChatSection reportId={report.id} />`。
- 对话区下方加「根据以上讨论重新生成」按钮（data-testid="regen-review-btn"）：
  - 点击先 `window.confirm('将根据以上讨论重新生成点评并覆盖当前内容，确认继续？')`，
    取消则不发请求；
  - 防抖：请求进行中按钮禁用且文案「重新生成中…」；
  - 成功：`setReport(data.report)`（新点评上屏，SharePosterButton 用新 report），
    显示成功提示（如「已根据讨论重新生成」，data-testid="regen-success"，可自动消失）；
  - 失败：按 status 映射上述中文提示（data-testid="regen-error"，role 不要用 alert——
    避免与页内其他 alert 冲突，用 data-testid 即可）。
- `SharePosterButton` 加 `key={report.id}`（海报预览随新报告强制刷新）。

### 2. `NextAdviceSection.jsx`

- 仅当 `report` 存在时：正文之后渲染 `<ReportChatSection reportId={report.id} />` +
  「重新生成下次建议」按钮（data-testid="regen-advice-btn"），交互与上面同款
  （confirm 文案「将根据以上讨论重新生成下次建议并覆盖当前内容，确认继续？」）；
  无报告时维持「暂无下次训练建议」，**不渲染按钮与对话区**。
- 成功 `setReport(data.report)`；422 按上述映射提示（并说明旧建议已清理）。

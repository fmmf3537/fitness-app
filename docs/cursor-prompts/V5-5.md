## 已核实的关键事实（实读代码，可直接采信）

### 后端 API（V5-1，base = `/api`，所有路由走 require_auth）
- `GET /api/coach/preferences` → `{preferences: [{id, content, category, tags, source, active, created_at, updated_at}]}`
- `POST /api/coach/preferences` body `{content, tags?}` → 新建 preference（content 幂等去重）
- `PUT /api/coach/preferences/{id}` body `{content?, tags?}` → 改 content/tags
- `DELETE /api/coach/preferences/{id}` → 软删（active=False）
- `GET /api/coach/drafts` → `{drafts: [{id, content, tags, source, status, created_at, resolved_at}]}`（默认 status='pending'）
- `POST /api/coach/drafts/{id}/accept` → `{preference: {...}}`（status='accepted' 或 'merged'）
- `POST /api/coach/drafts/{id}/reject` → `{ok: true}`
- 已读源码 `backend/app/api/coach_memory.py`：preferences_router / drafts_router 已合并到 router，main.py 注册 1 行

### 前端代码风格（实测）
- `frontend/src/App.jsx`：路由结构 `<RequireAuth><Layout>{pages}</Layout></RequireAuth>`，所有受保护页面平铺在 Layout 内
- `frontend/src/components/Layout.jsx:9-21` `NAV_LINKS` 数组 `{to, label, end?, badge?}` —— 新增条目只需追加一项
- `frontend/src/api/client.js`：`api(path, options)` 自动带 Bearer；错误 `ApiError(status, message, detail)`；401 自动 clearToken
- 页面风格：`pages/XxxPage.jsx` 导出 default 组件，useState/useCallback/useEffect，数据加载用 `api().then().catch()`，错误用 `setError(err.status === 401 ? '未登录' : err.message)`
- `data-testid` 是测试约定（既有 SettingsPage 等无 data-testid 也可，新页建议加便于测试）
- 项目用 Tailwind utility + 一些 hex 颜色（无 design system）

```
  - 空：隐藏整区
  - 非空：列表，每行 [content / tags / source / created_at] + 采纳 / 忽略按钮
```

#### 状态
```js
const [preferences, setPreferences] = useState([])
const [drafts, setDrafts] = useState([])

```

#### 关键函数
- `load()` —— 并行 `Promise.all([api('/api/coach/preferences'), api('/api/coach/drafts')])`，加载到 state；404/401 转 '未登录'；其他错误保留 message
- `handleCreate()` / `handleUpdate(prefId, payload)` / `handleDelete(prefId)` —— CRUD；调用后 reload
- `handleAcceptDraft(draftId)` / `handleRejectDraft(draftId)` —— 调用后 reload；按钮在请求中 disable（`resolveDraftId === draftId`）
- 错误展示统一 `<p role="alert">{error}</p>`；成功后短暂 setMessage 显示

#### 样式约定
- 卡片式列表，每行 `bg-white rounded-lg shadow-sm p-4 mb-3`
- 按钮：主操作 `bg-indigo-600 text-white px-3 py-2 rounded-md`；次操作 `bg-gray-200 text-gray-700`；危险 `bg-red-600 text-white`
- 内容显示用 prose：`whitespace-pre-wrap text-sm text-gray-900`
- tags 用小灰字：`text-xs text-gray-500 mt-1`
- source/category 标签：`text-xs px-2 py-0.5 rounded bg-gray-100 text-gray-600 mr-2`
- 草稿区用浅黄背景 `bg-amber-50` 区分正式条目

#### 关键交互
- 「新建须知」按钮：打开 Modal，editingPref = `{content: '', tags: ''}`，无 id
- 编辑：editingPref = `{id: pref.id, content: pref.content, tags: pref.tags || ''}`，PUT /api/coach/preferences/{id}
- 删除：`window.confirm("确定删除该须知？")`（与既有 WorkoutDetailPage 一致）→ DELETE
- 采纳草稿：POST /api/coach/drafts/{id}/accept → message "已采纳"
- 忽略草稿：POST /api/coach/drafts/{id}/reject → message "已忽略"

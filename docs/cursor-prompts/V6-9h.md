## 需求背景

V6-9g 后线上 292 条 high 抽查 20 条，只剩两类问题。审核方已决策：

**① 必须修（方向错误，1 条）**

```
TRX-后束飞鸟 → SUSPENSION/CHEST_FLY      ❌ 后束在背侧、Chest Fly 练前侧胸，练的肌肉相反
```
Garmin `SUSPENSION` 分类里有 `Y_FLY`（Suspension Y Fly，偏后束）等更合适的条目。

**② 保留但标注（器械不符，47 条）**

```
下斜杠铃卧推    → DECLINE_DUMBBELL_BENCH_PRESS   （Garmin 无杠铃下斜版）
窄距哑铃卧推    → CLOSE_GRIP_BARBELL_BENCH_PRESS  （Garmin 无哑铃窄距版）
上斜绳索夹胸    → INCLINE_DUMBBELL_FLYE
坐姿器械二头弯举 → SEATED_DUMBBELL_BICEPS_CURL
```
这些**动作家族与肌肉群是对的**，只是器械名不准。审核方决定**不降级**（降级会让这 47 个动作
整天无法同步，代价大于"名字不够精确"），改为在 `exercise_mapping.note` 里标注，
便于在管理页筛出来人工处理。

## 开发内容

### 1. `exercise_mapping_candidates.py`

#### 规则 R1：方向一致性（在 `_is_inconsistent` 的 `return False` 之前追加）

```python
    # 「后束」练背侧（后三角/后束飞鸟），而 Chest Fly 打的是前侧胸肌，
    # 是方向相反的两个动作；中文明确写「后束」时不得命中含 chest 的条目。
    if ("后束" in xunji_name or "后三角" in xunji_name) and "chest" in name_norm:
        return True
```

> 注意：**只针对「后束/后三角」**，不要扩成「反」——`反` 已经被
> `QUALIFIER_CONSISTENCY` 的 reverse 规则处理（反向飞鸟→reverse fly 是正常映射）。

#### 规则 R2：新增器械不符标注函数

```python
def equipment_mismatch_note(
    xunji_name: str, display_name: str | None
) -> str | None:
    """中文指定了器械、但 Garmin 条目的器械与之不同时，返回可读标注；否则 None。

    背景（2026-11-13 决策）：有些动作 Garmin 目录里**确实没有**同器械版本
    （如无「杠铃下斜卧推」「哑铃窄距卧推」）。此时映射到同动作家族的近似条目
    比让动作变成「无候选」更有用，但需要在 note 里如实标注，便于人工筛出。

    判定：
    - expected = 训记名里出现的器械中文对应的英文词根集合（忽略空串）
    - found    = display_name 里出现的所有器械英文词根集合
    - expected 非空且 found - expected 非空 → 判定器械不符
    """
```

**实现要点**：
- 用 `EQUIPMENT_TOKENS.items()` 判断「中文是否在 `xunji_name` 里」
- 用 `_norm(英文词根) in _norm(display_name)` 判断候选是否含该器械
- 空串值（`自重`/`徒手`）必须跳过，否则会把所有条目都算成"含空器械"
- 返回文案格式固定为：
  `f"器械不符：Garmin 条目为 {','.join(sorted(wrong))}，按动作家族近似映射"`
- 多个中文同义词指向同一英文词根（`绳索`/`龙门` → `cable`）时用集合去重

**不要**改打分、不要动 `_posture_bonus` / `_qualifier_penalty` / `_equipment_bonus`。

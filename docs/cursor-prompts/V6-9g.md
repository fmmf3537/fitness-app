## 需求背景

V6-9f 修好了七类严重错配（手腕弯举→二头、腿外展→肩外旋、器械划船→划船机等），
线上 301 条 high 抽查 20 条已无严重错误。但仍剩 **~24 条「家族对、变体错」**：

| 训记动作 | 现在映射到 | 问题 |
|---|---|---|
| 绳索夹胸 | `FLYE/SINGLE_ARM_STANDING_CABLE_REVERSE_FLYE` | **反向飞鸟练后束，夹胸练胸**——完全不同动作 |
| 绳索十字夹胸 | 同上 | 同上 |
| 平板绳索夹胸 / 上斜绳索夹胸 / 下斜绳索夹胸 | 同上 / `INCLINE_DUMBBELL_FLYE` / `DECLINE_DUMBBELL_FLYE` | 夹胸 ≠ 飞鸟 |
| 器械耸肩 | `SHRUG/BEHIND_THE_BACK_SMITH_MACHINE_SHRUG` | 器械 ≠ 史密斯机、也没说"背后" |
| 悍马机卧推 / 悍马多连杆卧推 | `BENCH_PRESS/INCLINE_SMITH_MACHINE_BENCH_PRESS` | 悍马 ≠ 史密斯、也没说"上斜" |
| 站姿自重提踵 | `CALF_RAISE/SINGLE_LEG_STANDING_CALF_RAISE` | 没说"单腿" |
| 绳索侧平举 / Y字绳索侧平举 | `LATERAL_RAISE/ONE_ARM_CABLE_LATERAL_RAISE` | 没说"单臂" |
| 绳索交叉后束飞鸟 / 绳索交叉反向飞鸟 | `FLYE/SINGLE_ARM_STANDING_CABLE_REVERSE_FLYE` | 没说"单臂" |

实测统计（V6-9f 后 308 条 high）：无端加单侧 **18 条**、器械误配史密斯 **3 条**，
另有夹胸类 **10 个动作**受影响。

**统一根因**：候选名里出现了**中文没要求的「限定词」**（single / alternating /
behind-the-back / reverse / seated / standing / incline / smith …）。
打分把「英文名里含这些词」当成纯加分项，从没惩罚「含了不该含的词」。

## 开发内容

### 1. `exercise_tokens.py` 新增两个常量

**a. 限定词一致性表**

> **重要范围约束**：只收「特异性限定词」（single/alternating/behind-the-back/reverse/
> seated/standing/incline/smith…），**不要**把器械词（dumbbell/barbell/cable/banded/
> kettlebell）放进来。原因：中文没写器械时通常是「不限定器材」，而不是「不是该器材」；
> 把器械纳入惩罚会大面积压低置信度，反而降低可用性。

```python
# 候选名里出现「中文没要求」的限定词时的扣分规则。
# 每项 = (候选名里要检查的英文写法, 中文名里必须出现的任一关键词)
QUALIFIER_CONSISTENCY: tuple[tuple[tuple[str, ...], tuple[str, ...]], ...] = (
    (("single", "one-arm", "one arm", "one-leg", "one leg"), ("单",)),
    (("alternating",), ("交替", "左右")),
    (("behind-the-back", "behind the back"), ("背后",)),
    (("reverse",), ("反",)),
    (("leaning",), ("斜身",)),
    (("side-lying", "side lying"), ("侧躺", "侧卧")),
    (("seated",), ("坐",)),
    (("standing",), ("站", "立")),
    (("kneeling",), ("跪",)),
    (("prone",), ("俯卧")),
    (("supine",), ("仰卧")),
    (("incline",), ("上斜",)),
    (("decline",), ("下斜",)),
    (("crossover",), ("夹胸",)),
)

QUALIFIER_MISSING_PENALTY = 20   # 每个「不该有」的限定词扣多少分
QUALIFIER_PENALTY_CAP = 40       # 单条候选最多扣多少分
```

**b. 动作同义展开表**

```python
# 同一中文动作在 Garmin 里可能有两种英文命名，匹配时都要试。
MOVEMENT_ALIASES: dict[str, tuple[str, ...]] = {
    "fly": ("crossover",),   # 夹胸：Cable Crossover 不含 "fly"，只靠 fly 永远找不到
}
```

### 2. `exercise_mapping_candidates.py` 三处改造

#### 规则 R1：限定词扣分（新增私有函数，在 `_posture_bonus` 之后调用）

```python
def _qualifier_penalty(xunji_name: str, name_norm: str) -> int:
    """候选名含中文没要求的限定词时返回负分（0 或 -20/-40）。

    背景：英文名里出现 single/alternating/behind-the-back/reverse/seated/standing/
    incline/smith 等词，若中文没有对应要求，说明这是「另一个变体」而不是同一动作。
    典型：「绳索夹胸」被判成 Single-arm Standing Cable Reverse Fly ——
    reverse fly 练后束、夹胸练胸，是完全不同的动作。
    """
    penalty = 0
    for eng_terms, zh_terms in QUALIFIER_CONSISTENCY:
        if not any(_norm(t) in name_norm for t in eng_terms):
            continue
        if any(z in xunji_name for z in zh_terms):
            continue
        penalty += QUALIFIER_MISSING_PENALTY
    return -min(QUALIFIER_PENALTY_CAP, penalty)
```

在打分循环里紧跟 `score += _posture_bonus(...)` 之后加：
```python
score += _qualifier_penalty(name, name_norm)
```

#### 规则 R2：史密斯硬排除（改 `_is_inconsistent`）

在函数末尾（`return False` 之前）追加：

```python
    # 史密斯机是独立器械，泛词 "machine" 也会命中 "Smith Machine"；
    # 中文没写「史密斯」时不应映射到史密斯机条目（实测误配 3 条）。
    if "smith" in name_norm and "史密斯" not in xunji_name:
        return True
```

> 注意：`史密斯机推举` 是 16 条 seed 之一，中文含「史密斯」，不受影响。

#### 规则 R3：动作同义展开（改 `_movement_alternatives`）

现有实现只做 `singlearm`/`onearm` 互通。改为**先展开 `MOVEMENT_ALIASES`、再做单臂互通**：

```python
def _movement_alternatives(mv: str) -> tuple[str, ...]:
    """同一动作的不同英文写法都要能匹配。

    - MOVEMENT_ALIASES：如 fly → crossover（夹胸在 Garmin 叫 Cable Crossover）
    - 单臂：Garmin 里 single-arm 与 one-arm 混用
    """
    alts: set[str] = set()
    for base in (mv, *MOVEMENT_ALIASES.get(mv, ())):
        norm = _norm(base)
        if not norm:
            continue
        alts.add(norm)
        if "singlearm" in norm:
            alts.add(norm.replace("singlearm", "onearm"))
        if "onearm" in norm:
            alts.add(norm.replace("onearm", "singlearm"))
    return tuple(alts)
```

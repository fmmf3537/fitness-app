### 1. `services/longterm_stats.py` 新建

至少导出：

```python
LONGTERM_WEEKS = 12  # 默认 12 周窗口（PRD-V5 §6.3）


def _last_n_weeks_range(anchor_date: date, weeks: int = LONGTERM_WEEKS) -> tuple[date, date]:
    """[anchor_date - weeks * 7, anchor_date) —— 不含锚点日当天。"""


def query_longterm_stats(
    session: Session,
    anchor_date: date,
    *,
    weeks: int = LONGTERM_WEEKS,
) -> dict | None:
    """返回 l3 段数据（dict 形态适配 build_memory_section 的 l3 参数）。

    返回字段（key → 中文 value 字符串）：
        训练频率: "X 次/周（Y 个训练日，共 Z 周）"
        总容量: "X kg（Y 次有效组）"
        平均时长: "X 分钟/次"
        平均热量: "X 千卡/次"
        部位分布: "胸 X kg / 腿 Y kg / 背 Z kg / ..."  （按容量降序取 top-5）
        PR 事件: "N 次突破历史最大重量"  （仅 N>0 时显示）
        体重趋势: "X.X kg（Δ±Y.Y）"  （仅当有 weight 数据且 delta != 0 时显示）

    全空（无训练数据）返回 None（与 build_memory_section 的 l3=None 行为一致）。
    """
```

实现要点：
- 调用 `query_period_training_summary(session, start, end)` 拿聚合值
- 调用 `query_pr_events(session, start, end)` 算 PR 次数
- 调用 `query_body_composition(session, start, end)` 拿 weight 趋势（delta 已有）
- **训练频率**：`training_days / weeks`（保留 1 位小数）
- **总容量**：`total_volume_kg` 直接用
- **平均时长**：`total_duration_s / 60 / workout_count`（整数分钟，0 workout 时跳过此字段）
- **平均热量**：`total_calories / workout_count`（整数）
- **部位分布**：取 part_distribution 按 volume_kg 降序前 5，格式 `胸 X kg`
- **PR 事件**：仅 `len(pr_events) > 0` 时显示
- **体重趋势**：仅 `body_composition["weight"]` 存在且 `delta != 0` 时显示
- 全部字段计算完毕后过滤掉 None / 空值 / 0 值（避免出现"训练频率：0 次/周"等噪声）

### 2. `services/memory_distill.py` 改 `compose_memory_section_for`

```python
def compose_memory_section_for(
    session: Session,
    workout_dict: dict | None,
    report_type: str,
    *,
    l3: dict | None = None,  # V5-3
) -> str:
    """build_query_tags + search_memory + list_preferences + build_memory_section。

    空数据返回 ""；检索/偏好查询失败时兜底返回 ""（不阻断主流程）。
    l3 由调用方预计算并传入（V5-3）。
    """
    try:
        query_tags = build_query_tags(workout_dict or {}, report_type)
        memories = search_memory(session, query_tags, limit=5)
        prefs = list_preferences(session, active_only=True)
        l1 = [p.content for p in prefs if p.content]
        l2 = [m.summary for m in memories if m.summary]
        return build_memory_section(l1, l2, l3)  # l3 直接传入
    except Exception as exc:
        logger.warning("V5-3 compose_memory_section_for 失败，返回空段：%s", exc)
        return ""
```

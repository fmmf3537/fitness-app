## 需求背景

V6-2 的候选生成器按**部位**缩窄 Garmin category：
`PART_TO_GARMIN_CATEGORIES[部位]`。但 Garmin 还有一批**器械专属分类**，
不按部位归属：

| 器械 | Garmin 专属分类 | 条目数 |
|---|---|---:|
| TRX / 悬吊 / 吊环 | `SUSPENSION` | 34 |
| 弹力带 / 弹力绳 | `BANDED_EXERCISES` | ~200 |
| 雪橇 | `SLED` | — |
| 轮胎 | `TIRE` | — |
| 沙袋 | `SANDBAG` | — |
| 战绳 | `BATTLE_ROPE` | — |
| 壶铃 | `HIP_SWING` | — |

这些分类**没进候选池**，导致器械类动作只能从部位分类里挑，选中错误的器械变体：

| 训记动作 | 当前映射（错） | 正确答案（就在 SUSPENSION/BANDED 里） |
|---|---|---|
| TRX-二头弯举 | `CURL / ALTERNATING_DUMBBELL_BICEPS_CURL` | `SUSPENSION / CURL`（Suspension Curl） |
| TRX-手枪深蹲 | `SQUAT / AIR_SQUAT` | `SUSPENSION / SINGLE_LEG_SQUAT` |
| 弹力带-深蹲 | `SQUAT / AIR_SQUAT` | `BANDED_EXERCISES / SQUAT`（Banded Squat） |
| 弹力带-侧平举 | `LATERAL_RAISE / ALTERNATING_LATERAL_RAISE_WITH_STATIC_HOLD` | `BANDED_EXERCISES / LATERAL_RAISE` |

实测影响（审核方已模拟）：206 条低置信里 **25 条能被修正**，无候选 219 条里再修 1 条。

## 已核实的关键事实（实读代码，可直接采信）

### `exercise_tokens.py`

- `EQUIPMENT_TOKENS: dict[str, str]`：中文 → 英文词根。已含
  `"悬吊": "suspension"`、`"TRX": "suspension"`、`"吊环": "ring"`、
  `"弹力带": "banded"`、`"弹力绳": "banded"`、`"雪橇": "sled"`、`"轮胎": "tire"`、
  `"沙袋": "sandbag"`、`"战绳": "battle rope"`、`"壶铃": "kettlebell"`、
  `"史密斯机": "smith machine"`、`"悍马机": "machine"` 等。
- `PART_TO_GARMIN_CATEGORIES: dict[str, list[str]]`：7 部位 + `"其他"`（空 list = 不窄化）。
  模块内有断言：所有值必须是 `exercises.CATEGORIES` 的真子集。
- `MOVEMENT_TOKENS` / `MOVEMENT_KEYS_BY_LENGTH`（长键优先）。

### `exercise_mapping_candidates.py` 的 `generate_candidates`

关键片段（**行号可能漂移，以代码为准**）：

```python
tokens = extract_tokens(name)
part = str(tokens["part"])
categories = list(PART_TO_GARMIN_CATEGORIES.get(part) or [])
equipment = list(tokens["equipment"])
postures = list(tokens["postures"])
movements = list(tokens["movements"])

if categories:
    cat_set = set(categories)
    pool = [e for e in catalog_rows if e.get("category") in cat_set]
else:
    pool = catalog_rows
```

打分（`score` 起始 20）：
- `_equipment_bonus(equipment, name_norm)` → 命中器械 **+40**；无器械词且名字里没有其它器械 → +20
- `_posture_bonus(postures, name_norm)` → 每个姿态 **+20**，上限 +40
- `_exact_bonus(exact_equip, mv, name_norm)` → 与 `"{器械} {动作}"` 完全相等 **+20**

分档（`_score_to_confidence`）：`>=60` high / `>=40` medium / 其余 low。

`_norm(text)` = 去除全部非字母数字后小写（`"Lat Pull-down"` → `"latpulldown"`）。

**注意**：`装备词根命中` 已经能给出 +40，所以只要器械专属分类进了候选池，
`Suspension Curl` 就会以 `20 + 40 = 60` 分排到 rank-1，**不需要额外加分也能修好**。

### 2. `exercise_mapping_candidates.py` 改造

**a. 新增常量**（模块级，放在 `_norm` 附近）：

```python
# 命中器械专属分类时的额外加分：确保它排在「仅部位命中」的候选之前
EQUIPMENT_CATEGORY_BONUS = 20
```

**b. 候选池合并**（替换现有 `categories` 计算之后到 `pool` 的那段）：

```python
part_categories = list(PART_TO_GARMIN_CATEGORIES.get(part) or [])
# 器械专属分类优先排在前面（既进池，也用于加分判定）
eq_categories = [
    EQUIPMENT_TO_GARMIN_CATEGORY[e]
    for e in equipment
    if e in EQUIPMENT_TO_GARMIN_CATEGORY
]
# 去重保序：器械分类在前，部位分类在后
categories = list(dict.fromkeys([*eq_categories, *part_categories]))

if categories:
    cat_set = set(categories)
    pool = [e for e in catalog_rows if e.get("category") in cat_set]
else:
    pool = catalog_rows
```

**注意**：`part_categories` 为空（部位「其他」）且 `eq_categories` 非空时，
`categories` 非空 → 会在这些器械分类里搜，而不是全目录。**这是期望行为**
（器械已经限定了范围），但**要保持**「两者都空 → 全目录」的既有语义。

**c. 打分时加器械分类加分**（在 `score += _exact_bonus(...)` 之后）：

```python
if eq_categories and entry.get("category") in eq_categories:
    score += EQUIPMENT_CATEGORY_BONUS
```

**d. 兜底路径也要传合并后的 categories**

现有 `_fallback_candidates(name, part, categories, catalog_rows, limit)` 调用
——把参数换成**合并后的** `categories`（不是 `part_categories`）。

**e. 不要改**：`_fallback_candidates` 的内部实现、`_equipment_bonus` /
`_posture_bonus` / `_exact_bonus` 的算法、`_score_to_confidence` 的阈值、`_norm`。

【当前任务】
改造 backend/app/models.py 中的 Setting 模型，使其从「单用户单行表」变为「每用户一行」。

当前 Setting 模型（需改造，来自 Sprint 9）：
- id: Integer, PK
- garmin_token_store: Text, nullable      # 注意：当前为明文存储
- xunji_api_key_enc: Text, nullable
- default_llm: String(50), nullable
- llm_keys_json_enc: Text, nullable
- created_at: DateTime

新 Setting 模型（每用户一行）：
- id: Integer, PK
- user_id: Integer, ForeignKey("users.id"), unique=True, nullable=True
- garmin_token_store_enc: Text, nullable      # 由原 garmin_token_store 改名（保留已有数据）
- garmin_email_enc: String(255), nullable
- garmin_password_enc: String(255), nullable
- xunji_api_key_enc: Text, nullable           # 保留
- xunji_body_api_key_enc: String(255), nullable
- default_llm: String(50), nullable           # 保留
- llm_keys_json_enc: Text, nullable           # 保留
- leaderboard_opt_out_json: Text, nullable    # JSON 字符串，如 {"frequency": false, "volume": true}
- created_at: DateTime, server_default=func.now()    # 保留
- updated_at: DateTime, server_default=func.now(), onupdate=func.now()  # 新增
